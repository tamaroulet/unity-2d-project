# unity-2d-project

## プロジェクト概要
Unity 2D を使用した育成シミュレーションゲームのプロジェクトです。
本プロジェクトの第一目的は「AIコーディングエージェントに実装をどこまで委譲できるか」の検証と工程記録を行うことであり、ゲーム自体は副次的な成果物となります。

## 開発環境
- Unity 6.3 LTS (6000.3.23f1) / 2D / Web ビルドターゲット
- JetBrains Rider（C# 実装）
- Antigravity + Unity-MCP（Unity エディタ操作）
- Jules（非同期タスク）

## 役割分担
`.cs` ファイルの書き込みは Rider に一本化されています。

## リポジトリ構成の注意
Unity プロジェクト本体はリポジトリのルートではなく、`Game/` 配下にあります。
また、`.gitignore` も `Game/` 配下に配置されています。
