# AGENTS.md

このファイルは、本リポジトリで作業するすべての AI エージェントに対する
恒久的な指示である。セッションをまたいで常に適用される。

---

## 0. 最優先事項

本プロジェクトは**一般的なゲーム制作ではない**。
第一の目的は「AIコーディングエージェントに実装をどこまで委譲できるか」の
検証と、その工程の記録である。動くゲームは副次的な成果物にすぎない。

したがって、以下を厳守する。

- 一般的なゲーム制作のベストプラクティスを、指示なく適用しない
- 「2Dゲームならこうするのが定石」という判断で先回りしない
- 何を作るかは人間が決める。エージェントは決めない

---

## 1. 事前承認の義務

**ファイルの作成・編集・削除、Unityエディタの状態変更、
ターミナルコマンドの実行は、すべて事前承認を必要とする。**

手順は以下に固定する。

1. 調査を行う（読み取りのみ。この段階で書き込みは一切行わない）
2. 変更計画を提示する。以下を必ず含めること
   - 作成・編集・削除するファイルの完全なパス
   - 各ファイルへの具体的な変更内容
   - 実行するコマンドの全文
   - 影響範囲
3. 人間の明示的な承認を待つ
4. 承認された範囲のみを実行する
5. 実行結果を報告する

### 禁止事項

- 「計画を提示します」と述べた同じ応答内で実装に着手すること
- 承認された範囲を超えて、関連する変更を「ついでに」行うこと
- フォルダ構成、レイヤー、タグ、プロジェクト設定を無断で整備すること

---

## 2. 開発・書き込み体制

開発体制は **Antigravity (Gemini) 完結体制** に移行した。（Claude Code の利用は停止）

- Antigravity は、指示書・仕様に基づき `.cs` ファイルの直接作成・編集、単体テストの作成、Unity エディタ操作（Unity-MCP 経由）、Git 管理を統合して実行する
- C# コードの実装・変更後は、必ず Unity-MCP の `refresh_unity` および `run_tests`（EditMode）を実行し、全テストの合格を機械的に検証すること
- Unity-MCP の `manage_script` および `execute_code` は無効化のままとし、ファイル編集は IDE 標準のファイルツール（write_to_file / replace_file_content）を用いる

---

## 3. 仕様確定前の実装禁止

現時点でゲームの仕様は確定していない。
仕様が本ファイルまたは別途の仕様書に記載されるまで、
ゲームロジックの実装に着手してはならない。

仕様が不明な状態で作業を求められた場合は、実装せずに
「仕様が未確定である」と報告すること。

---

## 4. 確定している制約

| 項目 | 内容 |
|---|---|
| Unity | 6.3 LTS (6000.3.x) |
| レンダリング | URP 2D |
| ビルドターゲット | **Web**（Unity 6 では「WebGL」ではなく「Web」と呼称する） |
| ビルド設定画面 | **Build Profiles**（旧称 Build Settings） |
| UI | uGUI（Canvas）。UI Toolkit は使用しない |
| Managed Stripping Level | Minimal または Low。High にしない |
| アセット | すべて人間が自作する。AI による画像・音声・3Dモデルの生成は行わない |
| ネットワーク機能 | 対象外 |

### 用語に関する注意

Unity 6 で名称が変更された項目がある。
学習データ上は旧名称の記述が多いため、以下を誤用しないこと。

- ブラウザ向けビルドは「Web」であり「WebGL」ではない
- 「Build Settings」は「Build Profiles」に改称されている

存在しない Unity の機能・API・パッケージ名を出力してはならない。
確信がない場合は「未確認」と明記すること。

---

## 5. 記録の方針

本プロジェクトでは工程の記録自体が成果物である。

- 1タスク = 1 Issue = 1 PR を原則とする
- 人間による修正は、AI の変更とは別のコミットに分離する
- コミットメッセージには、AI が生成したものか人間が書いたものかが
  判別できる情報を含める

---

## 6. 判断に迷った場合

指示の範囲が曖昧、または前提が不足していると判断した場合は、
推測で補完せず、**作業を止めて人間に確認すること。**

「おそらくこういう意図だろう」という補完が、
本プロジェクトで最も避けたい失敗である。
