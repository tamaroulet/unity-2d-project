## 目的

INV-6 が、ゲームの機能が 1 つ丸ごと死んでいることを数値で確定させた。

```
1 ラン（ターン 1〜24）を通した後の発火回数
  イベント: 0 回   ← ボス戦: 4 回 / ドラフト: 3 回 は正常
```

指示書 23 の検証 6（人間がターン 12 をマウスで通し、ダイアログが出ずターン 13 へ進んだ）と一致する。
**`GameEventCatalogSO` に登録されたイベントは、実装以来 1 度も画面に出ていない。**

指示書 23 で結線は直っている（`docs/snapshot/scene_bindings.txt` の `EventDialogView` は全項目結線済み）。
**結線の問題ではない。** 発火そのものが起きていない。

---

## 1. 検証すべき仮説

Architect 側で 1 つ仮説を持っている。**確認または反証すること。正しいと決めてかからないこと。**

### 仮説 H: ボス戦のターンとイベントのターンが衝突している

`GameFlowController.BeginTurn()` は次の順で処理する。

1. ターン開始時のレリック効果
2. **ボス戦の判定。該当したら処理して `return` する**
3. イベントの判定（`_eventResolver.Resolve`）
4. `WaitingInput` へ

ボス戦のターンは `{6, 12, 18, 24}` である。
そして人間が「出ない」と報告したのは**ターン 12** で、それはボス戦のターンである。

**イベントがボス戦と同じターンに設定されていれば、2 で `return` するため 3 に到達しない。**

### 観測してほしいこと

| # | 観測項目 | 出す値 |
|---|---|---|
| 1 | `GameEventCatalogSO` に登録された全イベントの一覧 | `EventId` / 名前 / トリガ種別 / **発火ターン**（`Instances/` の `.asset` の実値） |
| 2 | ボス戦のターン | `_bossBattleTurns` の実値 |
| 3 | 1 と 2 の重なり | 重なっているイベントを名指しする |
| 4 | `EventResolverSO.Resolve` が呼ばれた回数 | 1 ラン中に何回呼ばれたか（一時的なログ出力でよい） |
| 5 | そのうち `HasFired == true` になった回数 | 同上 |
| 6 | `_eventResolver` / `_eventCatalog` がシーンで結線されているか | スナップショットの該当行をそのまま貼る |

**4 と 5 で仮説の当否が決まる。**

- `Resolve` が **1 度も呼ばれていない** → 仮説 H が濃厚（またはより上流で止まっている）
- `Resolve` は呼ばれているが `HasFired` が常に false → 仮説 H は誤り。トリガ条件側の問題
- `HasFired` が true になっているのに画面が出ない → 結線か View 側の問題（指示書 23 の見落とし）

**どの枝に落ちたかを明記すること。**
