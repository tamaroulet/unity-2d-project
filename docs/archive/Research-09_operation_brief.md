## 現在の動線（実測）

1 サイクルの流れ。

```
1. 人間が判断役（Claude）と対話し、指示書を書かせる
2. 人間が実装役（Gemini）の画面へ移り「指示書 NN を実施」と貼る
3. 人間が完了を待つ
4. 人間が判断役へ戻り「終わった」と伝える
5. 判断役がレビューする
6. 人間が Unity を開き、マウスで動作を確認する
7. 1 へ戻る
```

**人間はすべての矢印の上に居る。**

2026-09-05 の実測: 約 13 時間で人間と判断役の往復が約 30 回。
このうち「決める」ためのやりとりと「運ぶ」ためのやりとりが混在している。

### 現在、人間の立ち会いが必要な作業

```

```

                    ただし画面なしで起動する経路も存在し、実際に 3 件の作業を完遂した実績がある

                    閉じて起動し直す方式だと 25 秒〜30 分超
