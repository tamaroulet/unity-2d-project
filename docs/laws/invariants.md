# Invariants (不変条件)

### INV-1 フェーズが進む
どのフェーズも WaitingInput または終端に到達せずに 10 秒以上留まらない。
塞いだ実バグ: エンディング停止（18）/ 敗北フリーズ（20）/ ショップ未結線（19）

### INV-2 終端エンディング通知
GamePhase.GameOver または GameClear に到達したら、EndingDecidedChannelSO が 1 ラン中に 1 回以上通知される。
塞いだ実バグ: 敗北時フリーズ・通知漏れ（20）

### INV-3 ブロッカー残存なし
WaitingInput の間、Canvas 配下に raycastTarget が true かつ Canvas を 90% 以上覆う Graphic が 1 つも無い。
塞いだ実バグ: ボスダイアログの透明ブロッカー残存（18）

### INV-4 フォントグリフ充足
表示中の全 TextMeshProUGUI について、割り当てフォントに全文字のグリフが存在する。
塞いだ実バグ: 日本語フォント未収録による豆腐（18）

### INV-5 ボタン到達性
表示中かつ interactable な全 Button について、中心座標への Raycast の最初が自分または子孫である。
塞いだ実バグ: コマンドボタンクリック不能・別要素による遮断（14 / 18）

### INV-6 サブシステム稼働
1 ラン（ターン 1〜24）を通した後、イベント発火・ボス戦・レリックドラフトがすべて 1 回以上発生する。
塞いだ実バグ: イベント未発火・サブシステム沈黙（23）
