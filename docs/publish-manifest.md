# 公開マニフェスト (Publish Manifest)

本マニフェストは、リポジトリ直下および `docs/` 直下に存在するすべてのパスについて、外部公開に含めるか否かを定義した文書である。

- **公開する**: 次のゲームでも意味を持つもの、読み手が使うもの
- **公開しない**: このゲームの作業記録。判断軸 15 の「使い捨て」に当たるもの

---

## 1. 公開する

| パス | 分類の根拠 |
| :--- | :--- |
| `.agents/` | AIエージェント向けの開発規約（development-rules.md）を含み、自律開発の共通規則として次のゲームでも利用するため。 |
| `.claude/` | Claude Code の設定および安全ガードフック（guard.js）であり、自律開発の安全機構として次のゲームでも利用するため。 |
| `.github/` | CI/CDワークフロー（unity-test, webgl-build, deploy_pages）および各種テンプレートであり、公開リポジトリの検証・運用に必要なため。 |
| `.vscode/` | AutoRunner タスク定義等の共通開発環境設定であり、次のゲームや開発者が環境を再現するために利用するため。 |
| `docs/` | 仕様書・設計判断・開発体制等の公開対象ドキュメントを格納するディレクトリであるため。 |
| `Game/` | Unity プロジェクト本体（C# スクリプト、アセット、設定）であり、ゲームおよび自律開発の主要成果物として読み手が利用するため。 |
| `scripts/` | テスト実行・自律ランナー・検査スクリプト群であり、自律開発パイプラインの実行基盤として次のゲームでも再利用するため。 |
| `.gitattributes` | 改行コードおよび Git LFS 属性等のリポジトリ挙動を正しく保つための共通設定であるため。 |
| `.gitignore` | リポジトリの除外設定であり、不要な中間ファイルやキャッシュの混入を防ぎ整合性を保つため。 |
| `.mcp.json` | Unity MCP サーバーの接続構成であり、AIエージェントとエディタの連携環境構成に必要なため。 |
| `README.md` | プロジェクト全体の背景・協調アーキテクチャ・ノウハウを説明する中核文書であり、読み手が最初に参照するため。 |
| `docs/auto-runner-setup.md` | 自律継続実行環境（Auto Runner）のセットアップ手順および構成解説であり、開発環境の再現に利用するため。 |
| `docs/decisions/` | アーキテクチャ決定記録（ADR）であり、設計の根本理由として恒久的な価値を持ち次のゲームでも参照するため。 |
| `docs/game-overview.md` | ゲーム全体のルール・ループ・UI構成・データ一覧を網羅したマスター概要書であり、読み手がゲーム仕様を理解するために利用するため。 |
| `docs/laws/` | 不変条件（invariants）および失敗の型（failure-modes）を定めた恒久文書であり、自律開発の核となる知見であるため。 |
| `docs/publish-manifest.md` | 本公開マニフェストであり、リポジトリの公開対象および非公開対象の定義を読み手と検査に示すため。 |
| `docs/README.md` | ドキュメント全体の構造案内であり、リポジトリの読み手が利用するため。 |
| `docs/research/` | 自律開発体制・スタジオ構想（Autonomous Studio）に関する調査分析レポートであり、読み手および将来の指針として有用であるため。 |
| `docs/spec/` | ゲームの仕様書・コーディング仕様・ビルド仕様であり、読み手や開発者がゲーム仕様を理解・実装するために利用するため。 |
| `docs/status.md` | プロジェクトの実装到達点およびテスト通過状況を要約したステータス文書であり、読み手が現状を把握するために利用するため。 |
| `docs/strategy/` | 個人AIゲーム開発の戦略および自律開発スタジオ構想文書であり、次のゲームでも意味を持つ恒久知識であるため。 |
| `docs/webgl/` | GitHub Pages 上でブラウザ試遊を可能にする WebGL ビルド成果物および公開ページであり、読み手がプレイするために利用するため。 |
| `docs/workflow/` | 人間とAIの協調プロトコル（Handoff / Triad）およびオンボーディング規約であり、自律開発体制の共通仕組みとして次のゲームでも利用するため。 |

## 2. 公開しない

| パス | 分類の根拠 |
| :--- | :--- |
| `harness/` | 外部リポジトリ（C:/dev/harness）へ移行済みの空ディレクトリ残骸であり、本リポジトリの公開対象外であるため。 |
| `logs/` | テスト実行結果やランナーログなど、ローカル環境での過去の作業記録（判断軸 15 の使い捨て）であるため。 |
| `docs/archive/` | 過去の調査資料や古い仕様等の作業記録であり、人間の裁定（2026-09-06）および判断軸 15 により公開対象から外す使い捨て文書であるため。 |
| `docs/cycles/` | 各開発サイクルの詳細作業記録であり、人間の裁定（2026-09-06）および判断軸 15 により公開対象から外す使い捨て文書であるため。 |
| `docs/nightly/` | 過去の日次朝刊レポート・レビューログであり、このゲームの作業記録（判断軸 15 の使い捨て）であるため。 |
| `docs/snapshot/` | 特定時点でのシーン内結線状態の一時スナップショット（作業用ログ）であり、このゲーム特有の作業記録（使い捨て）であるため。 |
