# 設計判断の記録 (ADR)

このディレクトリは、アーキテクチャや設計に関する重要な判断の記録（ADR: Architecture Decision Record）を保管する場所です。

## ADRの目的
プロジェクトが進行する中で行われた設計上の選択の背景、理由、およびその結果を記録することで、将来の開発メンバーが当時の意図を理解できるようにします。

## ADRの作成方法
新しくADRを作成する際は、`0000-template.md` をコピーして新しいファイルを作成し、必要事項を記入してください。
ファイル名は `連番-タイトル.md` のようにします（例: `0001-use-unity-lts.md`）。
